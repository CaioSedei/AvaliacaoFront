Sobre HTML

HTML não é uma linguagem de programação, mas sim umma linguagem de marcação que usa tags para descrever o conteúdo. Cada tag informa ao navegador como exibir o conteúdo.

Sobre CSS

CSS permite que você crie designs bonitos e reponsivos, adaptando-se a diferentes tamanhos de tela e dispositivos.

Oque é JavaScript

JavaScript é executado no navegador do usuário, permitindo criar experiência interativas sem precisar recarregar a pagina
